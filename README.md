# Otus. Автоматизация тестирования на Java (Домашнее задание #1)

## 📌 Цель задания

Реализовать 3 автотеста с использованием **Selenium WebDriver 4+**, **DI (Guice)**, **Stream API**, **jsoup**, и **двухуровневого тест-дизайна (Page Object)**.

---

## ✅ Реализованные сценарии

### Сценарий 1: Поиск курса по названию

- Открывается страница https://otus.ru/catalog/courses
- Выполняется поиск курса по имени (данное передаётся в тест)
- Переход на карточку курса
- Проверка, что заголовок на открытой странице соответствует ожидаемому (используется `jsoup`)

### Сценарий 2: Поиск самого раннего и самого позднего курса

- Открытие всех курсов через кнопку "Показать ещё"
- Использование Stream API + `reduce` для поиска курса с самой ранней и самой поздней датой начала
- Проверка, что заголовок и дата на странице курса соответствуют ожидаемым (через `jsoup`)

### Сценарий 3: Переход в случайную категорию

- Открытие главной страницы https://otus.ru
- Наведение на меню "Обучение" с использованием `Actions`
- Выбор случайной категории
- Проверка, что открылся каталог с курсами этой категории

---

## 🧰 Используемые технологии

- Java 17+
- Maven
- JUnit 5 (`@ExtendWith`)
- Google Guice (Dependency Injection)
- Selenium WebDriver 4.x
- WebDriverManager (автоматическая настройка драйвера)
- Jsoup
- Stream API, Optional, reduce
- Подсветка элементов через `WebDriverListener`
- Page Object + двухуровневый тест-дизайн
- Линтеры: Checkstyle, SpotBugs (по шаблону с занятия)
